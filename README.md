# betting-digest

This repository holds the daily betting digest feed for [Bet Lab](https://civic-rose-frost-cabin.grok.me).

The file [`latest.json`](./latest.json) is the current day's digest. Prior days are in [`digests/`](./digests/). Bet Lab's Digest tab loads `latest.json` from the raw GitHub URL.

These picks are decision support, not guarantees. Any bet can lose.

Raw feed URL:

https://raw.githubusercontent.com/alexaceto/betting-digest/main/latest.json
